# ELVIS video evidence

`elvis-v2-alpha2-operator-preview-course/` is a historical documentation
archive for the offline `v2.0.0-alpha.2` operator preview. It contains no V2
trading runtime, no production-course render and no publication approval. Its
existing transcript is not a screenshot and is not accepted against the
revised capture-command manifest without a fresh capture.

The future trajectory-B/1B production course is a separate G17 project created
only after the exact public runtime release passes G16. It must bind that
release digest, use its own deterministic offline build, rights/provenance
manifest, accessibility QA, screenshots, narration, captions, Studio preview
and explicit render/publication approval. Historical alpha.2 files must never
be renamed or rewritten as production evidence.
