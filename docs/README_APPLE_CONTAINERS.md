## Quick Start Guide

ELVIS (Enhanced Leveraged Virtual Investment System) is now fully containerized and optimized for Apple's Container application and Apple Silicon Macs.

### ⚡ **One-Line Setup**
```bash
./scripts/apple_container_elvis.sh setup
```

### 🚀 **One-Line Start**
```bash
./scripts/apple_container_elvis.sh start
```

### 📊 **Access Dashboard**
- **Trading Dashboard**: http://localhost:5050
- **Grafana Metrics**: http://localhost:3001 (requires the `observability` profile, see below)

## 🔧 **Configuration**

### **Environment Variables**
The compose stack reads two files:
- `.env` - used by docker-compose for `${...}` substitution (API keys, external ports)
- `.env.container` - injected into the bot container via `env_file` (copy from `.env.container.example`)

```bash
# Trading Configuration
TRADING_MODE=paper
STRATEGY_MODE=ensemble
HIGH_FREQUENCY_TRADING=true
LEVERAGE=100

# Paper Trading Balances
INITIAL_USDT_BALANCE=1000.0
INITIAL_BNB_BALANCE=1000.0

# Expose the trade-history API outside the container
# (it binds 127.0.0.1 by default, so the published 5050 port
# is only reachable from the host with this set)
TRADE_API_HOST=0.0.0.0

# API Keys (optional for paper trading)
BINANCE_FUTURES_TESTNET_API_KEY=your_key_here
BINANCE_FUTURES_TESTNET_API_SECRET=your_secret_here
```

### **Container Resources** (from the generated `docker-compose.apple.yml`)
```yaml
ELVIS Bot:    2GB RAM, 2 CPU cores
PostgreSQL:   512MB RAM, 1 CPU core  
Redis:        256MB RAM, 0.5 CPU cores
Prometheus:   512MB RAM, 0.5 CPU cores
Grafana:      256MB RAM, 0.5 CPU cores
```

## 🛠️ **Troubleshooting**

### **Common Issues**

1. **Docker not running**
   ```bash
   # Start Docker Desktop
   open -a Docker
   ```

2. **Port conflicts**
   ```bash
   # Check what's using ports
   lsof -i :5050 -i :3001 -i :9090 -i :5433 -i :6380
   ```

3. **Container build fails**
   ```bash
   # Clean and rebuild
   docker system prune -f
   ./scripts/apple_container_elvis.sh setup
   ```

4. **Database connection errors**
   ```bash
   # Wait for PostgreSQL to initialize
   ./scripts/apple_container_elvis.sh logs
   ```

### **Debug Commands**
```bash
# Check all container status
docker-compose ps

# View specific service logs
docker-compose logs postgres
docker-compose logs redis
docker-compose logs elvis-bot

# Connect to ELVIS container
docker-compose exec elvis-bot /bin/bash

# Test database connection
docker-compose exec elvis-bot python -c "from utils.paper_trade_db import get_conn; print('DB OK' if get_conn() else 'DB Error')"
```
